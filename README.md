# AI Research Journal

Notes from building, testing, and learning with AI systems.

I'm Hasan. I came to this work through hands-on use of Claude Code and a persistent urge to understand how things work—not just how to get a model to produce an answer. This repository is a working journal of projects, experiments, design decisions, and lessons that changed how I approach AI-assisted engineering.

This is a practitioner journal, not an academic publication or a claim to be an AI researcher by title. Some entries describe prototypes; others reflect on applied work whose details cannot be shared publicly.

## What I write about

- **LLM evaluation and reliability:** how to test model judgments, look for unsupported claims, and avoid mistaking confident output for correct output.
- **Human oversight:** where people need to inspect, approve, or correct an AI-assisted workflow.
- **Agentic development:** using coding agents while keeping requirements, verification, and responsibility clear.
- **Reproducible systems:** recording decisions and measurements so that a result can be checked again.

## How I work with AI

I use Claude Code and other AI tools as active implementation collaborators. I don't claim that every line in an AI-assisted project was written manually by me. My work includes identifying the problem, asking questions, setting constraints, choosing and reviewing designs, defining tests, investigating failures, and deciding whether the result is acceptable. I try to make that division of work explicit in each entry.

## What is deliberately not here

This repository is separate from my private project repositories. It does not contain employer source code, private datasets, internal rubrics or prompts, account data, credentials, session transcripts, raw media, or copied game source. Some applied work is described only at a high level while I check what I am permitted to disclose. I will add detail only when it is safe and appropriate to do so.

The experiments here are small and contextual unless stated otherwise. A result from one test setup should not be read as a general model capability claim. I will try to record limitations and failed approaches alongside useful results.
